# 🌐 Настройка сети

## ⚠️ Общая информация

По умолчанию шлюзы HDL LINK используют сеть:
192.168.10.0/24
Если ваша сеть отличается — устройства не будут обнаружены.

---

# 🔌 Настройка шлюза MGWIP

## Когда это нужно

- шлюз не находится в HDL Studio  
- сеть отличается от 192.168.10.x  
- нет связи с устройствами  

---

## 1. Прямое подключение

1. Подключите шлюз к ПК через Ethernet  
2. Нажмите `Win + R`  
3. Введите: ncpa.cpl
4. Откройте свойства Ethernet  

---

## 2. Настройка IP на ПК

Задайте IP вручную:

- IP: `192.168.10.10`  
- Маска: `255.255.255.0`  

---

## 3. Поиск шлюза

1. Откройте вкладку **IP Config**  
2. Выберите сетевой интерфейс  
3. Нажмите **Search**  
4. Добавьте шлюз в проект  

---

## 4. Настройка IP шлюза

Выберите один из вариантов:

### Статический IP

- Укажите адрес вне DHCP-пула  
- Пример: `192.168.1.200`

### DHCP

- Включите получение IP автоматически  

---

## ⚠️ Важно

IP адрес не должен попадать в диапазон, который раздаёт роутер.

---

## 5. Обновление списка IP

Если адреса не обновились:

- закройте вкладку IP Config  
- откройте снова  

---

# 🖥 Настройка панелей Source

## Особенность

IP задаётся на самой панели.

---

## Wi-Fi подключение

1. При первом запуске выберите язык  
2. Выберите сервер **HDL Russia**  
3. Подключитесь к Wi-Fi  
4. Введите пароль  

IP назначится автоматически.

---

## Ethernet подключение

1. Подключите кабель  
2. Выберите:
   - DHCP  
   - или статический IP  

---

## ⚠️ Ограничения

### Data+ / Data-

Нельзя подключать если:

- в сегменте уже есть другой шлюз  

Это может вызвать:

- конфликт сети  
- петлю по IP  

---

## 💡 Рекомендация

Если есть MGWIP → делайте его Master  
Панели Source → Slave

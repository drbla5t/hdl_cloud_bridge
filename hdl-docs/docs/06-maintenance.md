# 🛠 Обслуживание и восстановление

# 🔓 Отвязка шлюза

1. Откройте настройки устройства  
2. Перейдите в **More**  
3. Нажмите: **Unbind gateway**
4. Выполните поиск устройств  

Статус должен стать: **Unbound**

---

## ⚠️ Важно

Привязанный шлюз нельзя добавить в другой проект.

---

# 🔄 Сброс шлюза

## Сброс конфигурации

1. Перейдите в **More**  
2. Нажмите **Clear data**  
3. Введите пароль: **85521566**
---

## Что сбрасывается

- роли  
- функции  
- сценарии  

---

## Что НЕ сбрасывается

- IP настройки  

---

# 🌐 Сброс сети

1. Удерживайте кнопку **Prog** 35 сек  
2. Дважды нажмите  

IP станет: **192.168.10.250**
---

# 🖥 Сброс панели Source

## Полный сброс

**Настройки → Инфо → Заводской сброс**

---

## Удаление проекта

**Настройки → Управление аккаунтом → Отвязать**

---

# 💾 Резервное копирование

1. Откройте **Device data Backup**  
2. Выберите устройства  
3. Нажмите: **Export selected device**
---

# ♻️ Восстановление

1. Перейдите в **Device data restore**  
2. Откройте файл `.BUSPROJ`  
3. Выберите устройства  
4. Нажмите: **Confirm to restore**

---

# 🔄 Обновление драйверов

1. Подключитесь по MQTT  
2. Перейдите в **Drivers**  
3. Откройте **Driver OTA**  
4. Выберите драйвер  
5. Установите  

---

## Рекомендация

Сначала обновляйте:

1. Bus Driver  
2. Затем LINK Driver  

---

# 📦 Device Catalog

## Предварительная настройка

1. Добавьте виртуальное устройство  
2. Найдите по артикулу  
3. Укажите количество  

---

## Применение к устройству

1. Подключите физический модуль  
2. Совместите:
   - Subnet  
   - Device ID  

3. Нажмите: **Automatic match**
---

## Результат

Устройство станет: **Online**

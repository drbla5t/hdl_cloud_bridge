# 🔐 Передача доступа заказчику

## Подготовка

Перед передачей:

- завершите настройку  
- протестируйте систему  

---

## Изменение статуса проекта

1. Откройте HDL Studio  
2. Найдите проект  
3. В поле **Debug status** установите: **To be delivered**
---

# 📱 Способ 1 — через AIoT

1. Перейдите в AIoT Platform  
2. Откройте **Operation Platform**  
3. Перейдите: **Communication Center → Project Management**
4. Выберите тип проекта  
5. Найдите проект  
6. Нажмите: **QR Code to Delivery**
7. Передайте QR заказчику  

---

# 💻 Способ 2 — через HDL Studio

1. Установите статус **To be delivered**  
2. Нажмите на иконку QR  
3. Сохраните файл  
4. Передайте заказчику  

---

# 📲 Способ 3 — через приложение

1. Откройте проект  
2. Перейдите в настройки  
3. Найдите: **Передача прав резиденции**
4. Сгенерируйте QR  
5. Передайте заказчику

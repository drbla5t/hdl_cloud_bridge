# 🧠 Подключение Home Assistant

После настройки проекта:

1. Откройте в браузере **Home Assistant**  
2. Настройки → Люди → Пользователи → Добавить ползователя
3. Создайте имя пользователя и пароль для MQTT (Потребуется позже)
4. Перейдите в Настройки → Приложения → Установить приложения
5. Установите **Mosquitto broker** и запустите его
6. Перейдите в Настройки → Приложения → Установить приложения → ⋮ → Репозитории → Добавить:
7. Добавьте https://github.com/drbla5t/hdl_cloud_bridge/
8. Вернитесь в Настройки → Приложения → Установить приложения
9. Уставновите HDL MGWIP Cloud Bridge и перейдите в Конфигурация
10. Заполните поля:


hdl_user: your@yandex.ru  |Логин клиента от AIoT платформы
hdl_pass: your_password.  |Пароль клиента от AIoT платформы
hdl_server: ru            |Выбор региона сервера
mqtt_host: core-mosquitto |Можно не менять, это адрес Mosquitto broker
mqtt_port: 1883           |Можно не менять, это порт Mosquitto broker
mqtt_user: ""             |Укажите имя из пункта 3
mqtt_pass: ""             |Укажите пароль из пункта 3
poll_interval: 60         |Время опроса устройств, рекомендуется 60, тк нужно ТОЛЬКО в случае сбоя
home_names:               |Укажите название вашего объекта по проекту STUDIO из раздела Project name

***можно добавить несколько объектов***

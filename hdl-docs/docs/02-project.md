# 🏗 Создание проекта и тестирование

## Подготовка

1. Установите HDL Studio  
2. Запустите программу  
3. При необходимости смените язык  

---

## Обновление HDL Studio

1. Откройте меню **Help**  
2. Выберите **Check for updates**  
3. Установите обновление при наличии  

Или скачайте актуальную версию вручную.

---

## Создание проекта

1. Нажмите **New Project**  

2. Заполните поля:
   - название проекта  
   - регион  
   - адрес  
   - тип системы  

3. Нажмите **Sure**

> 💡 Название можно вводить на русском  
> 💡 Адрес можно указать или оставить прочерк  

---

## Поиск устройств

1. Перейдите в поиск устройств  
2. Нажмите **Search**  
3. Дождитесь списка устройств  

---

## Добавление устройств

1. Выберите нужные устройства  
2. Нажмите **+Current project**  

---

## Создание структуры (этажи и комнаты)

1. Откройте **Floor and Room**  
2. Нажмите **+Area** (создать этаж)  
3. Введите название  

### Добавление комнаты

1. Нажмите **Add Sub-area**  
2. Введите название комнаты  
3. Нажмите **Sure**

---

## Привязка устройств к комнатам

1. Откройте настройки устройства  
2. Найдите поле **Floor**  
3. Выберите этаж и комнату  
4. Нажмите **Save**

---

## Настройка шлюза

1. Откройте топологию проекта  
2. Перейдите в настройки шлюза  

### Установите:

- Роль: **Master**  
- Connection: **MQTT**  
- Server:  ru-gateway.hdlcontrol.com
3. Укажите местоположение:
 - Auto locate  
 или  
 - вручную  

4. Нажмите **Save**

---

## Роли шлюзов

- Master — только один  
- Остальные — Slave  
- Для Slave:
- уникальный Subnet ID  
- Device ID = 0  

---

## Применение настроек

1. Нажмите **Read**  
2. Нажмите **Apply secret key**  
3. Дождитесь успешного сообщения  

---

## Выгрузка проекта

1. Нажмите **Upload project**  
2. Выполните повторный **Read**  

Статус должен стать: Online

---

## Если не работает

Проверьте:

- местоположение  
- время  
- повторите Apply secret key  
- наличие кнопки Bind gateway  
- обновите драйверы  

---

## Добавление функций

### Buspro

1. Перейдите во вкладку **Functions**  
2. Нажмите **+Buspro Func**  
3. Выберите функции  
4. Нажмите **Save**  
5. Выполните **Upload**

---

### KNX

1. Нажмите **+KNX Func**  
2. Укажите:
   - название  
   - комнату  
   - тип функции  
   - подтип  

3. Укажите адреса:
   - управляющий  
   - обратной связи  

4. Нажмите **Save**  
5. Выполните **Upload**

---

## Проверка

1. Войдите в HDL Home  
2. Откройте проект  
3. Проверьте устройства

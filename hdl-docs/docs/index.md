# 🏠 Настройка HDL Home и Яндекс Алисы

Полная инструкция по настройке шлюзов HDL LINK (MGWIP, Source), приложения HDL Home и интеграции с Яндекс Алисой.

---

## 🚀 Быстрый старт

1. Получить доступ к AIoT платформе  
2. Установить HDL Studio  
3. Установить приложение HDL Home  
4. Создать аккаунт заказчика  
5. Создать проект  
6. Добавить устройства  
7. Настроить сеть  
8. Выгрузить проект  
9. Передать доступ заказчику  
10. Подключить Яндекс Алису  

---

## 📋 Требования

- Доступ к AIoT платформе  
- HDL Studio (последняя версия)  
- Приложение HDL Home  
- Аккаунт Яндекс  

---

## ⚠️ Важно

- Шлюзы по умолчанию работают в сети `192.168.10.0/24`  
- В системе может быть только **один Master-шлюз**  
- Остальные устройства должны быть в режиме **Slave**
